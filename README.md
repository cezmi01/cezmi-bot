# cezmi-bot

`cezmi-bot`, henüz iskelet hâlinde olan bir projedir. Bu depo şu an için sadece temel dokümantasyonu içerir.

## Amaç

- Otomasyon/agent tabanlı bir “bot” projesi için başlangıç noktası sağlamak
- Kurulum, geliştirme ve konfigürasyon notlarını tek yerde toplamak

## Hızlı başlangıç

1. Depoyu klonlayın:

```bash
git clone <REPO_URL>
cd cezmi-bot
```

2. Proje yapısını oluşturun (kod eklendikçe bu bölüm güncellenecek).

## Geliştirme

- Bu repo şu an tek commit ve minimum içerikle başlatıldı.
- Kod/bağımlılık eklendiğinde aşağıdaki bölümler güncellenecek:
  - Çalıştırma komutları
  - Ortam değişkenleri / konfigürasyon
  - Test ve lint adımları

## Konfigürasyon (planlanan)

- `.env` ile ortam değişkenleri
- Yerel geliştirme ayarları

## Lisans

- Lisans bilgisi henüz eklenmedi.
